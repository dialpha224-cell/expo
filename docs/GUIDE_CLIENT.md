# 📖 Guide Utilisateur AfroCrown - Clients

## Bienvenue sur AfroCrown !

AfroCrown est votre plateforme pour découvrir et réserver chez les meilleurs salons de coiffure Afro. Ce guide vous accompagne dans l'utilisation de l'application.

---

## 🚀 1. Premiers Pas

### 1.1 Créer un compte
1. Rendez-vous sur [afrocrown.com](https://salon-dashboard-48.preview.emergentagent.com)
2. Cliquez sur **"Connexion"** puis **"Connexion avec Google"**
3. Autorisez l'accès
4. Votre compte est créé automatiquement !

### 1.2 Application Mobile
Téléchargez l'app AfroCrown sur :
- 📱 **Google Play Store** (Android)
- 🍎 **App Store** (iOS - bientôt)

---

## 🔍 2. Trouver un Salon

### 2.1 Recherche par lieu
1. Sur la page d'accueil, utilisez la section **"Trouver un Salon"**
2. Sélectionnez votre **pays** et **ville**
3. Cliquez sur **"Rechercher"**
4. Parcourez la liste des salons

### 2.2 Géolocalisation
- Cliquez sur **"Me localiser"** 📍
- Les salons les plus proches s'affichent

### 2.3 Réservation Urgente ⚡
Besoin d'un créneau dans les 2 prochaines heures ?
1. Cliquez sur le bouton **"Réservation urgente"** (rouge)
2. Autorisez la géolocalisation
3. Découvrez les salons avec des créneaux immédiats !

---

## 📅 3. Réserver un Rendez-vous

### 3.1 Processus de réservation
1. **Choisir un salon** : Cliquez sur un salon dans la liste
2. **Choisir un coiffeur** : Sélectionnez votre coiffeur préféré
3. **Choisir une coupe** : Parcourez les coupes et tarifs
4. **Choisir date & heure** : Sélectionnez un créneau disponible
5. **Confirmer** : Vérifiez et validez votre réservation

### 3.2 Option Premium (+20%)
Certains salons proposent une option Premium :
- Service prioritaire
- Plus de temps consacré
- Produits haut de gamme

### 3.3 Confirmation
Après réservation, vous recevez :
- ✉️ Email de confirmation
- 📱 Notification push (si app installée)
- 📋 Récapitulatif dans "Mes Rendez-vous"

---

## 📋 4. Mes Rendez-vous

### 4.1 Voir mes RDV
- Menu → **"Mes Rendez-vous"** (web)
- Onglet **"Rendez-vous"** (app mobile)

### 4.2 Statuts
| Icône | Statut | Signification |
|-------|--------|---------------|
| 🟡 | En attente | Attente de confirmation du salon |
| 🟢 | Confirmé | RDV validé, présentez-vous à l'heure ! |
| ✅ | Terminé | Prestation effectuée |
| 🔴 | Annulé | RDV annulé |

### 4.3 Annuler un RDV
- Ouvrez le RDV concerné
- Cliquez sur **"Annuler"**
- ⚠️ Annulez au moins 24h avant pour éviter des frais

---

## 🤖 5. Simulation IA (Essayage Virtuel)

### 5.1 Comment ça marche
1. Menu → **"Simulation IA"**
2. Parcourez les **30+ styles** disponibles
3. Sélectionnez une coupe
4. Cliquez sur **"Générer Vue 360°"**
5. Découvrez le résultat sous 3 angles : Face, Profil, Dos

### 5.2 Catégories de styles
- **Dégradés** : Taper Fade, Low Fade, Skin Fade, etc.
- **Waves** : 360 Waves
- **Afro** : Afro naturelle, High Top, Flat Top
- **Courts** : Buzz Cut, Crâne rasé
- **Tresses** : Cornrows, Box Braids, Fulani
- **Locks** : Dreads courts, Dreads longs, Freeform
- **Naturel** : Twists, Coils, Twist Out
- **Tendance** : Edgar Cut, Mohawk, Frohawk

### 5.3 Utiliser la simulation
- Montrez le résultat à votre coiffeur pour obtenir exactement le style souhaité !

## ⭐ 7. Avis & Notes

### 7.1 Laisser un avis
Après chaque RDV terminé :
1. Allez dans **"Mes Rendez-vous"**
2. Trouvez le RDV concerné
3. Cliquez sur **"Laisser un avis"**
4. Donnez une note (1-5 étoiles)
5. Écrivez votre commentaire
6. **Publier**

### 7.2 Critères d'évaluation
- Qualité de la coupe
- Accueil et service
- Propreté du salon
- Rapport qualité/prix

## 🏆 10. TrimConnect Battle

### 10.1 Qu'est-ce que c'est ?
TrimConnect est le plus grand concours de coiffure Afro !
- Les coiffeurs soumettent leurs créations
- Les clients votent pour leurs préférées
- Les gagnants remportent des prix

### 10.2 Comment voter
1. Menu → **"TrimConnect"**
2. Parcourez les participations
3. Cliquez sur **"Voter"** pour vos préférées
4. Vous pouvez voter pour plusieurs créations !

## 🔔 12. Notifications

### 12.1 Types de notifications
- 📅 Rappel de RDV (24h avant)
- ✅ Confirmation de réservation
- 🔴 Annulation
- 🎁 Promotions exclusives
- 🏆 Nouveau badge VIP gagné

### 12.2 Gérer les notifications
1. Allez dans votre profil
2. Ouvrez **"Préférences de notification"**
3. Activez/désactivez :
   - Rappels de RDV
   - Promotions
   - Notifications push
4. Définissez le **max messages/semaine** (1 à 7)

## ❓ FAQ

### Comment annuler un rendez-vous ?
Mes Rendez-vous → Sélectionnez le RDV → Annuler

### Comment contacter un salon ?
Ouvrez la fiche du salon → Bouton "Appeler" ou "Email"

### Je n'ai pas reçu de confirmation ?
Vérifiez vos spams. Si rien, contactez support@afrocrown.com

### Puis-je modifier mon RDV ?
Annulez et recréez une nouvelle réservation.

### Comment récupérer mon mot de passe ?
Utilisez "Connexion avec Google" ou contactez le support.
