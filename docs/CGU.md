# Conditions Générales d'Utilisation - AfroCrown

*Dernière mise à jour : Mars 2026*

Les présentes Conditions Générales d'Utilisation (CGU) régissent l'utilisation de la plateforme AfroCrown, accessible via le site web et l'application mobile.

## 2. Définitions

- **Plateforme** : Site web et application mobile AfroCrown
- **Utilisateur** : Toute personne utilisant la plateforme
- **Client** : Utilisateur réservant des services de coiffure
- **Salon** : Établissement de coiffure partenaire

## 4. Services Proposés

### 4.1 Pour les Clients
- Réservation de rendez-vous

- Achat de produits capillaires
- Programme de fidélité
- Participation aux concours TrimConnect

### 4.2 Pour les Salons
- Gestion des rendez-vous
- Gestion des coiffeurs
- Statistiques et analytics
- Vente de produits
- File d'attente virtuelle

## 5. Réservations

### 5.1 Processus
1. Sélection du salon et de la coupe
2. Choix du coiffeur et du créneau
3. Confirmation et paiement
4. Réception du QR code de confirmation

### 5.2 Annulation
- Gratuite jusqu'à 24h avant le RDV
- Frais possibles pour annulation tardive
- Le salon peut refuser les clients avec annulations répétées

### 5.3 Non-présentation
- En cas de non-présentation sans annulation, le client peut être facturé
- 3 non-présentations peuvent entraîner une suspension

## 6. Paiements

### 6.1 Moyens de paiement

- Paiement sur place (selon salon)

### 6.2 Sécurité
- Paiements sécurisés par Stripe (PCI-DSS)
- AfroCrown ne stocke pas les données bancaires

### 6.3 Remboursements
- Selon politique du salon
- Demande via support@afrocrown.com
