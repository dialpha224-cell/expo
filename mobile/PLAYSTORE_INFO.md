• Trouvez des salons près de chez vous par géolocalisation
• Consultez les disponibilités en temps réel

• Recevez des rappels pour vos rendez-vous

🤖 SIMULATION IA EXCLUSIVE
• Essayez plus de 30 styles de coiffures sur votre photo
• Vue à 360° pour visualiser le résultat sous tous les angles
• Trouvez le style qui vous correspond avant de vous engager
• Partagez vos simulations avec vos amis

🛍️ MARKETPLACE
• Découvrez les meilleurs produits capillaires
• Recommandations personnalisées
• Achetez directement depuis l'app

🏅 TRIMCONNECT BATTLE
• Participez au plus grand concours de coiffure afro
• Votez pour vos créations préférées
• Gagnez des prix exceptionnels
• Rejoignez une communauté passionnée

📱 FONCTIONNALITÉS
• Interface intuitive et moderne
• Mode sombre élégant
• Notifications de rappel
• Historique de vos rendez-vous
• Programme de fidélité

Rejoignez des milliers d'utilisateurs qui font confiance à AfroCrown pour leur coiffure !

## Commandes pour générer l'APK

### 1. APK de test (pour installer sur téléphone)
```bash
cd /app/mobile
npx eas-cli build --platform android --profile preview --local
```

### 2. AAB pour Play Store (production)
```bash
cd /app/mobile
npx eas-cli build --platform android --profile production
```

### 3. Soumettre au Play Store
```bash
cd /app/mobile
npx eas-cli submit --platform android --profile production
```
